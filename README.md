# remotion-videos

Vídeos animados do **Seletividade Com Amor**.

## Sobre

Este repositório contém vídeos animados criados com [Remotion](https://www.remotion.dev/), uma framework para criar vídeos programaticamente com React.

## Pré-requisitos

- Node.js 18+
- npm ou yarn

## Como começar

```bash
npm install
npm start
```

## Estrutura do projeto

```
src/
  compositions/   # Composições de vídeo
  components/     # Componentes reutilizáveis
  assets/         # Imagens, fontes e outros recursos
```
